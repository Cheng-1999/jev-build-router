# WP02 — Wire `typesafe_select` and `typesafe_category` through `decision.py`

## Why

WP01 added `ig_places/decision.py` (`backend()`, `model()`, `enabled()`,
`client(timeout=, retry=)`). The two TypeSafe rungs still hard-code Jev. This
package routes them through the seam so `DECISION_BACKEND=clef` switches both,
and **nothing else changes**.

## What to change

`ig_places/typesafe_select.py`
- `enabled()`: `decision.enabled() and daily_usd() > 0` (the purse gate stays;
  `TYPESAFE_DAILY_USD` keeps its name — it is the rung's purse, whatever backend).
- `_get_client()`: `decision.client(timeout=TIMEOUT_S, retry=RetryPolicy(max_retries=0, timeout=None))`.
  Keep the lazy SDK import, the lock and `_reset_for_tests()`. The cached
  client must be rebuilt when the backend or model changes between calls
  (tests flip env; in production env is fixed at boot) — key the cache on
  `(decision.backend(), decision.model())`.
- `pick()`: `aicost.record(ACTION, decision.model(), resp)`.
- `select_name()` trail step: model field = `decision.model()`.
- **Keep `MODEL = "jev-1.13.0"`** as a module constant: `tools/typesafe_eval.py`,
  `ig_places/video_eval.py` and `typesafe_category.MODEL` import it, and the
  eval cache is keyed on it. Add a one-line comment that production reads
  `decision.model()`.
- Docstring: one short paragraph on the backend switch, pointing to
  `decision.py` (do not duplicate its rules).

`ig_places/typesafe_category.py`: same three substitutions (enabled gate, the
`aicost.record` model, the trail model). It already reuses
`typesafe_select._get_client()`; keep that.

`ig_places/video_eval.py`: read it; if it records a model name, switch it to
`decision.model()` too. Do not otherwise touch it.

## Invariants (the existing checks must keep passing unchanged)

- Keyless (`TYPESAFE_API_KEY=""`, backend unset): the rung does not exist — no
  trail step, no request, byte-identical behaviour.
- `TYPESAFE_DAILY_USD <= 0` still switches the rung off.
- `smoke_test.py`'s `_no_typesafe` replaces `typesafe_select._request`; both
  backends must still go through `_request`, so the guard covers Clef too.

## Tests (smoke_test.py, next to the existing tier 0c checks ~line 13680)

- With `DECISION_BACKEND="clef"`, `CLOUDFLARE_ACCOUNT_ID`/`CLOUDFLARE_AI_TOKEN`
  set to stub values and `typesafe_select.pick` / `_request` stubbed the way the
  existing tier 0c checks stub them: the trail step's model is `clef-flash`,
  and `aicost` recorded the call under `clef-flash`.
- Same for the category rung.
- `DECISION_BACKEND="clef"` with `TYPESAFE_API_KEY` set but no Cloudflare keys:
  the rung is OFF (it must not fall back to Jev).
- `DECISION_BACKEND="bogus"` with every key set: OFF.
- Restore every env var in `finally`, with `""`, never pop.
- Inject a bug (e.g. leave `aicost.record` on `MODEL`) and confirm a check goes
  red, then restore. Report which bug you injected.

## Out of scope

`decision.py` itself (WP01 — if you find a bug there, report it, do not
rewrite it), eval tools (WP03), docs (WP04).

# WP03 — Eval harnesses: `--backend jev|clef|local`

## Why

NAMING_ARCHITECTURE rule 1: no rung ships, or changes model, without a
before/after on the same gold set, same mode, per source. The harnesses that
produce those numbers are `tools/typesafe_eval.py` (tier 0c name select) and
`tools/category_eval.py` (category select). Both hard-code Jev today.

A local Clef server is available for free measurement: the community MLX port
`clef_mlx.py serve` exposes `POST http://127.0.0.1:8000/v1/systemone` with
Jev's request and response shapes (no key). Hosted Clef is reached through
`ig_places/decision.py` (WP01).

## What to change (both tools, same shape)

New flags:
- `--backend {jev,clef,local}` (default `jev`).
- `--base-url URL` — only with `--backend local`; default `http://127.0.0.1:8000`.
  **Refuse any host that is not loopback** (`127.0.0.1`, `localhost`, `::1`):
  this flag exists to talk to a server on this machine, and the captions in the
  gold set are users' posts.
- `--model`: per backend. jev: pinned `jev-X.Y.Z` (existing check). clef:
  `clef` or `clef-flash`. local: free text, default `local-clef` — it is the
  cache key, so tell the user in `--help` to name the variant
  (`clef-flash-4bit`, `clef-4bit`).

Behaviour:
- `local`: free, so it does **not** need `--spend-real-money` and needs no key.
  Build the client as `TypeSafeClient(api_key="local", base_url=<base-url>,
  model=<model>, timeout=120, retry=RetryPolicy(max_retries=1, timeout=None))`.
  Set the base URL on the client only; leave `TYPESAFE_BASE_URL` blanked at
  import exactly as today.
- `jev`: unchanged, behind `--spend-real-money`.
- `clef`: behind `--spend-real-money`; client from
  `decision.client(...)` with `DECISION_BACKEND=clef` set for the process, and
  the price from `aicost._price_for(model)` for the usd_billed line.
- **Cache key includes backend and model** (bump `CACHE_VERSION`; old cached
  Jev entries must still be found for `--backend jev`; migrate them or key Jev
  exactly as before, your choice, but say which). A local answer can never be
  returned for a Jev or Clef lookup, or the reverse.
- Record per-row wall latency for live (non-cached) answers; print p50 / p95 /
  max per run under the existing summary, and `n` the stats cover.
- The default invocation (no flags) prints exactly what it prints today.
- Keep `ask()` importing the SDK lazily, the row-level error handling, and the
  "one bad row never ends the run" rule.

Do not change the questions, the candidate builder, the judge, or the gold set.

## Tests

- `smoke_test.py`: add checks that (a) `--backend local --base-url
  http://10.0.0.5:8000` exits non-zero without a request, (b) the cache key for
  the same state differs across backend/model, (c) a Jev cache entry is not
  returned for `--backend local`. Drive the functions directly; no network, no
  subprocess to a real server.
- Run `tools/typesafe_eval.py --limit 5` (free coverage mode) and paste the
  output in your report to show the default path still works.
- Inject a bug (drop backend from the cache key) and confirm a check goes red,
  then restore. Report which bug you injected.

## Out of scope

`ig_places/*` (WP01/WP02), docs (WP04), running any paid evaluation.

# WP01 — Decision backend seam: `ig_places/decision.py`

## Why

Two production rungs ask a System One decision model a closed-set question:
`ig_places/typesafe_select.py` (tier 0c, pick the venue name out of the
caption's own spans) and `ig_places/typesafe_category.py` (pick the category).
Both talk to TypeSafe's Jev through `typesafe_sdk.TypeSafeClient`
(`typesafe_select._get_client`, which `typesafe_category` reuses).

Cloudflare released Clef / Clef-flash (2026-10-01): same System One API
(`noul` / `choice` / `score`, same answer JSON), hosted on Workers AI, open
weights. This package adds the seam that lets those rungs run on either
backend. **It does not wire the rungs** (that is WP02) and **does not change
any default behaviour**.

## What to build

New module `ig_places/decision.py`:

```python
BACKEND_ENV = "DECISION_BACKEND"          # "" | "jev" | "clef"
JEV_MODEL = "jev-1.13.0"                  # == typesafe_select.MODEL today; keep them equal
CLEF_MODELS = ("clef", "clef-flash")
CLEF_MODEL_ENV = "DECISION_CLEF_MODEL"    # default "clef-flash"
CF_ACCOUNT_ENV = "CLOUDFLARE_ACCOUNT_ID"
CF_TOKEN_ENV = "CLOUDFLARE_AI_TOKEN"
CF_MODEL_PATH_ENV = "DECISION_CF_MODEL_PATH"   # default "@cf/cloudflare/<model>"
CF_API = "https://api.cloudflare.com/client/v4/accounts/{account}/ai/run/{path}"

def backend() -> str            # "jev" | "clef" | "invalid"  (blank/unset -> "jev"; case-insensitive, stripped)
def model() -> str              # pinned model name for the active backend (trail + aicost key)
def enabled() -> bool           # jev: TYPESAFE_API_KEY set; clef: account AND token set AND model valid; invalid: False
def client(*, timeout: float, retry) -> "TypeSafeClient"
```

- `backend()`: anything other than blank / `jev` / `clef` returns `"invalid"`.
  **Fail closed**: `enabled()` is False for `invalid`; never fall back to the
  other backend (a typo must not silently send captions to a different
  company). `DECISION_CLEF_MODEL` outside `CLEF_MODELS` makes `enabled()`
  False under `clef` too.
- `client()` for **jev**: exactly what `typesafe_select._get_client` builds
  today — `TypeSafeClient(model=JEV_MODEL, timeout=timeout, retry=retry)`.
  Do not pass a key or base_url; the SDK reads `TYPESAFE_API_KEY` /
  `TYPESAFE_BASE_URL` itself as it does now.
- `client()` for **clef**: `TypeSafeClient(api_key=<CLOUDFLARE_AI_TOKEN>,
  model=model(), timeout=timeout, retry=retry, transport=CloudflareTransport(...))`.
  `CloudflareTransport` subclasses `httpx2.BaseTransport` (the SDK's HTTP
  library is `httpx2`; check `typesafe_sdk/_core/transport.py` for how it is
  used). It wraps an inner transport (default `httpx2.HTTPTransport()`;
  injectable for tests) and on each request:
  1. Only `POST .../v1/systemone` is allowed; anything else -> raise.
  2. Rewrites the URL to `CF_API` with the account id and model path. Keep
     method, body and the `Authorization: Bearer` header the SDK set.
  3. On the response, if the JSON body has `result` (dict) and no `answers`,
     return a new response whose body is `result` (same status, JSON
     content-type). If `success` is false or the status is not 2xx, return the
     original status with a body the SDK's error extraction can read
     (`typesafe_sdk/_core/errors.py::extract_message`: put Cloudflare's first
     `errors[].message` under `{"error": {"message": ...}}`).
  The Cloudflare base URL must not depend on `TYPESAFE_BASE_URL`.
- The SDK must keep being imported lazily (function-level), as
  `typesafe_select` does today: no SDK import at app boot.
- Pinned model names only. Never `jev-latest`.

`ig_places/aicost.py` `_PRICES`: add `"clef": (0.24, 0.0)` and
`"clef-flash": (0.09, 0.0)` (USD per million input / output tokens, Workers AI
list price 2026-10-01), with a comment in the style of the Jev line, and make
sure the `AI_PRICE_<MODEL>` override works for both (`clef-flash` ->
`AI_PRICE_CLEF_FLASH`).

`.env.example`: document the five new names, commented out, with one line each.
Note on `DECISION_CF_MODEL_PATH`: the Workers AI id for clef-flash has not been
confirmed from Cloudflare's docs; default to `@cf/cloudflare/<model>` and say
"verify at developers.cloudflare.com/workers-ai/models before enabling".

## Tests (smoke_test.py)

1. At the **top** of `smoke_test.py`, beside the TypeSafe lines, set to `""`
   (never pop — CLAUDE.md): `DECISION_BACKEND`, `DECISION_CLEF_MODEL`,
   `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_AI_TOKEN`, `DECISION_CF_MODEL_PATH`.
   Comment why, in the voice of the neighbouring comments.
2. A new block `# --- decision backend (ig_places/decision.py) ---` with
   `check(...)` lines, each restoring env in a `finally`:
   - blank env -> backend "jev", model "jev-1.13.0", enabled False
   - `DECISION_BACKEND="clef"` with no account/token -> enabled False
   - `DECISION_BACKEND="Clef "` -> "clef" (case/space tolerant)
   - `DECISION_BACKEND="cloudflare"` -> "invalid", enabled False even with every key set
   - `DECISION_CLEF_MODEL="clef-pro"` -> enabled False
   - transport, with a fake inner transport that records the request and
     returns a Cloudflare envelope: URL becomes
     `https://api.cloudflare.com/client/v4/accounts/acct/ai/run/@cf/cloudflare/clef-flash`,
     the Bearer header is preserved, and a full `client(...).system_one(...)`
     call with a `Choice` + `Noul` question returns a `SystemOneResponse` whose
     `.choices` / `.nouls` / `.usage.input_tokens` read the unwrapped values
   - a `success: false` envelope with HTTP 400 surfaces as a `TypeSafeAPIError`
     (or the SDK's equivalent) carrying Cloudflare's message
   - a non-systemone path raises
   - `aicost._price_for("clef-flash") == (0.09, 0.0)`
3. Backstop like `_no_typesafe`: wrap `decision.CloudflareTransport`'s default
   inner transport so a request that reaches the real network in a test
   raises, and add a tally check `no test ever made a real Cloudflare call`.
4. Inject a bug (e.g. drop the envelope unwrap) and confirm a check goes red,
   then restore. Say in your report which bug you injected.
